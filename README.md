# AI Round Table

> 让浏览器中的多个 AI 围绕一个话题展开辩论，自动调度发言、传递观点、推动共识。

## 这是什么？

一个 Chrome 浏览器插件，你在多个标签页打开不同的 AI（ChatGPT、Kimi、Gemini、DeepSeek...），插件自动：

1. 接收你输入的话题
2. 向每个 AI 发送初始观点请求
3. 读取每个 AI 的回复
4. 将 A 的观点转发给 B、C、D，要求它们回应
5. 循环往复，直到达成共识或你终止
